# Credit Card Fraud Detection - Project Workspace

This directory contains the core source code for the Credit Card Fraud Detection machine learning system, including:

- **api/**: FastAPI backend.
- **frontend/**: React/Vite dashboard source code.
- **pipeline/**: Prefect training and evaluation flow orchestration.
- **src/**: Data processing, EDA, and model training utilities.
- **models/**: Model registry holding serialized `.pkl` models.
- **artifacts/**: Metrics, evaluation reports, and Evidently HTML pages.

For full setup and usage instructions, please refer to the main repository [README.md (Root)](../README.md).
